About Dragonfly

Dragonfly is a decentralized mirror for openly-licensed machine-learning models. It distributes model weights peer-to-peer over Iroh, so open models stay downloadable even when a single host is slow, rate-limited, or offline — while Hugging Face remains the canonical source of record.

Listing policy. Only models and datasets released under a permissive or open license (Apache-2.0, MIT, and the recognized open-weight community licenses) are indexed and seeded. Content that is proprietary, gated, or not cleared for redistribution does not belong here and will be removed on request. To report a listing, open an issue on GitHub.

How it works

  • The tracker keeps a live index of what peers are currently seeding, exposed at /contents.
  • Categories (LLM, Embeddings, Datasets, Apps) and formats (GGUF, SafeTensors) let you filter the registry.
  • Each download is content-addressed and SHA-256 verified after transfer, then re-seeded automatically.
  • The registry cross-checks Hugging Face so you can see, at a glance, what is available upstream vs. peers-only.

Fetch a model

Grab any model from the registry with the dfget client:

dfget --p2p-tracker https://<this-host> hf://<org>/<repo>/<file>

GGUF quantizations use the gguf:// scheme; every other Hugging Face format uses hf://.

Run a peer

Seeding is how the mirror stays healthy. Point dfget at a model you already have and it will announce, verify, and serve it to the swarm. See the client README for setup.
